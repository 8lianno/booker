# Security Policy

## Supported Versions

The following versions of Booker are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take security vulnerabilities very seriously. 

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them directly via **GitHub Security Advisories** on this repository (go to the "Security" tab -> "Advisories" -> "Report a vulnerability"). 

If you prefer direct contact, please reach out to the maintainers privately.

### What to Include
When reporting a vulnerability, please provide the following details:
* A description of the vulnerability.
* Steps to reproduce the issue.
* The potential impact on the system or users (e.g. data exposure, arbitrary code execution, etc.).

### Response Timeline
You should receive a preliminary response acknowledging receipt of your report within 48 hours. We will keep you updated on the progress of addressing the vulnerability, and we aim to resolve all critical security issues within 7-14 days.

Thank you for helping keep the Booker project secure!
